## Exactness State

The lanes are not yet full live 1:1 replications. They are the necessary
materialized substrate for that work:

- real one-sample datasets are present for EvoSkill, Trace2Skill, D2Skill, and
  SkillReducer;
- prompt/setup source files are copied into per-paper lane reports;
- prompt/setup preflights are rendered from those samples where possible;
- Memento-Skills is honestly blocked on gated GAIA/HLE access;
- Codex with `gpt-5.4-mini` remains the intentional model substitution.

Next implementation pass should adapt the per-paper runners to consume these
`tmp/paper_exact_lanes/*/lane.json` reports, starting with Trace2Skill and
EvoSkill because their real samples and prompt surfaces are most concrete.

`scripts/run_paper_exact_lanes.py` is now the first adapter layer. It consumes
the materialized samples directly and writes per-paper prompt/report bundles.
