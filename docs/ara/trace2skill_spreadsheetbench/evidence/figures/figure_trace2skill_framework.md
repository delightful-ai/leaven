## Caption

Overview of Trace2Skill's three-stage pipeline. Stage 1 rolls out a frozen
agent on the evolving set using an initial skill and produces labeled success
and failure trajectories. Stage 2 runs parallel error and success analysts over
individual traces to propose skill patches. Stage 3 merges patches into a
single consolidated update through inductive reasoning and programmatic
conflict prevention, producing an evolved skill.
