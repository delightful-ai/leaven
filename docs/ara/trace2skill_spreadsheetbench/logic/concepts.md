# Concepts

## Skill Directory
- **Notation**: `S = (M, R)`
- **Definition**: A structured, human-readable directory rooted at `SKILL.md` (`M`) plus auxiliary resources (`R`) such as scripts, references, and assets.
- **Boundary conditions**: Applies to portable declarative agent guidance; does not include model parameter updates.
- **Related concepts**: Initial Skill, Evolved Skill, Skill Patch.

## Trajectory Corpus
- **Notation**: `T = {tau_i}`, partitioned into `T-` and `T+`
- **Definition**: The set of task execution traces generated by a fixed agent with an initial skill over the evolving set.
- **Boundary conditions**: The paper uses trajectories from the evolving set; held-out test tasks must not be used for evolution.
- **Related concepts**: Evolving Set, Error Analyst, Success Analyst.

## Skill Patch
- **Notation**: `p_i`
- **Definition**: A proposed edit to the skill directory produced by an analyst from one trajectory and a frozen initial skill.
- **Boundary conditions**: A patch is not the final skill; it must survive validation and consolidation.
- **Related concepts**: Patch Pool, Merge Operator, SkillPatchPlan.

## Patch Pool
- **Notation**: `P = P- union P+`
- **Definition**: The set of independently produced error- and success-derived skill patches.
- **Boundary conditions**: Analysts must not see each other's patches before consolidation.
- **Related concepts**: Analyst Independence, Hierarchical Consolidation.

## Hierarchical Consolidation
- **Notation**: `M(pi_theta, S0, {p_i}) -> p*`
- **Definition**: A merge process that deduplicates, resolves conflicts, preserves unique insights, and produces one consolidated patch.
- **Boundary conditions**: The paper requires programmatic guardrails for non-existent file targets, overlapping line edits, and skill format validity.
- **Related concepts**: Merge Batch Size, Prevalent Pattern Bias, Final Patch.

## Reproduction Denominator
- **Notation**: `D_proof`
- **Definition**: The exact scope a Leaven run proves, such as one-case, subset, held-out split, seed aggregate, cross-model, or full paper.
- **Boundary conditions**: Smaller denominators cannot be labeled full 1:1 reproduction.
- **Related concepts**: Result Overlay, Proxy Proof.

## Paper Target
- **Notation**: `Y_paper`
- **Definition**: A numeric value transcribed from the Trace2Skill paper/source tables.
- **Boundary conditions**: A paper target is not a Leaven result.
- **Related concepts**: Leaven Result, Evidence Table.

## Leaven Result Overlay
- **Notation**: `Y_leaven`
- **Definition**: A denominator-labeled result generated by Leaven and plotted against paper targets.
- **Boundary conditions**: Must include run id, source command, artifacts, model, seed, dataset slice, and proof classification.
- **Related concepts**: Reproduction Denominator, Closeout Audit.
